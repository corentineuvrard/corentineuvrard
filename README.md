# Corentin Euvrard

Computer vision and generative AI engineer, based in Korea.

For the past two years I have been building image and video generation pipelines that run in production: diffusion models orchestrated with ComfyUI, served through FastAPI and Docker on GPU servers, with offscreen 3D rendering to produce depth, normal and part maps for conditioning. Much of my recent work is about keeping these pipelines fast and within GPU memory: deciding which models stay loaded, which ones are released between steps, and sharing models across pipelines.

## Featured project

**[ComfyUI-SMPL](https://github.com/corentineuvrard/ComfyUI-SMPL)**: ComfyUI nodes that turn a height and a weight into an SMPL / SMPL-H body, then output a shaded render, an exact silhouette mask, a depth map and 24 body-part masks for ControlNet-style conditioning.
